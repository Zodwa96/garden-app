## About

The Garden App is a simple command-line application that helps gardeners know what tasks to perform based on the current month and season. It provides seasonal gardening advice and monthly tasks to keep your garden healthy throughout the year.

This project was created as part of the  Data Science, Algorithms and Advanced Software Engineering course to demonstrate Git workflow practices, including:

- Creating and managing issues on GitHub
- Using feature branches for development
- Writing clean, well-documented code
- Creating pull requests with proper issue references
- Following professional software development workflows



## Features

- Seasonal Advice: Get gardening tips based on the current season (Spring, Summer, Autumn, Winter)
- Monthly Tasks:  Know what garden tasks to perform each month
- Easy to Use:  Simple command-line interface - just run and go
- Well Documented:  Full docstrings and type hints for all functions
- Modular Design:  Cleanly organized functions with single responsibilities
